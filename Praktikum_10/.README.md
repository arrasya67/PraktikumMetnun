# Tugas Metode Numerik: Penyelesaian Persamaan Diferensial Biasa (PDB)

Program ini dibuat untuk menyelesaikan persamaan diferensial biasa (PDB) menggunakan bahasa pemrograman **GNU Octave / MATLAB**. Tugas ini bertujuan untuk membandingkan tingkat akurasi dari beberapa metode numerik dalam menyelesaikan PDB.
## 👤 Identitas Pembuat
*   **Nama:** Dwi Agus Maulana 
*   **NIM:** L0325022 
*   **Kelas:** 3B 
  
## 📌 Informasi Soal
*   **Persamaan Diferensial:** `dy/dx = (4x^3 - 2x + 1) / (2 + y)`
*   **Kondisi Awal:** `y(0) = 1`
*   **Batas Akhir:** `x = 2`
*   **Jumlah Iterasi (n):** 15
*   **Ukuran Langkah (h):** 0.1333333333

## ⚙️ Metode yang Digunakan
Program ini menghitung nilai pendekatan `y(2)` dan galat (error) menggunakan empat pendekatan:
1.  **Metode Analitik (Eksak)** - Sebagai nilai acuan sebenarnya.
2.  **Metode Euler** (Orde-1)
3.  **Metode Heun** (Runge-Kutta Orde-2)
4.  **Metode Runge-Kutta Orde-4 (RK4)**

## 🚀 Fitur Program
*   Menampilkan tabel iterasi langkah-demi-langkah untuk masing-masing metode numerik.
*   Menampilkan tabel perbandingan nilai `y(x)` di setiap langkah antara nilai eksak dan ketiga metode.
*   Menghitung **Galat Absolut** dan **Galat Relatif (%)** untuk masing-masing metode.
*   Menampilkan kesimpulan otomatis mengenai metode dengan galat terkecil.
*   Menghasilkan **Grafik 1:** Visualisasi perbandingan kurva solusi pendekatan terhadap garis eksak.
*   Menghasilkan **Grafik 2:** Visualisasi perbandingan galat absolut menggunakan skala logaritmik (semilog).
