# 📘 TUGAS SPL METODE NUMERIK

## Deskripsi Program

Program ini merupakan implementasi **lima metode numerik** untuk menyelesaikan **Sistem Persamaan Linear (SPL)** berukuran 5×5 menggunakan **GNU Octave/MATLAB**. Program ini dibuat untuk memenuhi tugas mata kuliah **Metode Numerik** dan mencakup analisis **solusi**, **galat (error)**, serta **running time** dari setiap metode.
